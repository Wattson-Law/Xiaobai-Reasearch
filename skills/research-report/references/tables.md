# 表格规范

## 六类常用表格

1. 发展阶段一览表（放在"技术背景"节）：列建议为"阶段 / 时间 / 标志性事件或文献 / 政策背景 / 技术特征"，把技术发展历程切成一览式时间线。
2. 分类体系表（放在"系统分类"节）：列建议为"类别 / 系统 / 定位 / 典型产品 / 自制或采购判断"，把整个领域切成可调研的类目，并在最后一列给出分层结论（自研 / 采购 / 拆开及其理由），正文再用一段解读这一列的依据。
3. 竞争格局表（放在"竞争格局"节）：列建议为"厂商 / 梯队 / 代表产品 / 市场地位或市占率"。
4. 厂商对比表（每个"主要产品与厂商"节一张，是主体部分反复使用的核心表）：列建议为"厂商 / 产品 / 定位与核心功能 / 技术特点或代表案例"。
5. 难点矩阵表（结论章一张，全文难点在此收口）：列建议为"难点 / 具体表现 / 类型（机理、感知、决策、安全、证据）/ 成熟度 / 可突破顺序"。每一行都要在前文某章出现过，不在矩阵里引入新内容。
6. 速查表（附录A/B）：列建议为"系统类别 / 推荐厂商 / 代表产品 / 选型要点"，横向速查。
7. 视需要补充功能模块清单表、分期实施计划表。

## 表题与放置

- 每张业务表上方加独立表题，只写"表1""表2"……按全文顺序编号，不根据内容自拟标题。
- 表题宋体 12 pt、黑色、居中。
- 表格前用一句话引出，例如"系统分类体系如表1所示"。

## 表格格式

- 白底黑字；外框与内部网格均为 0.5 pt 黑色实线，不加粗外框。
- 表头行加粗、水平垂直居中；表体宋体 12 pt。
- 短值（序号、金额、日期、市占率）水平居中，叙述性长文本左对齐，单元格垂直居中。
- 按内容设定列宽，不平均分配；序号、价格等窄列给窄宽。
- 表格宽度锁定在版心内；跨页时重复表头行，单个高行允许自然拆分。

## 内容要求

- 同一批被调研对象使用同一套列，保证可横向对比。
- 价格、市占率、案例数等数字必须来自资料；空值保留，不编造。
- 表格内长文本不写成完整段落，拆成短句或短语，便于扫描对比。
