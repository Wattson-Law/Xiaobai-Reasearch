# Changelog

All notable changes to **Xiaobai-Research** will be documented in this file.

## [v1.0.0] - 2026-11-03

### Added
- **DeepSeek Harness (Cordis) Plugin Integration**: Added `package.json`, `cordis.patch.yml`, and `lib/index.js` registering `check_research_report_threads` and `build_research_report_docx` native tools.
- **9-Chapter Research Methodology & Dual-Thread Framework**:
  - Section 2.1 Novice-friendly plain-language technology evolution timeline.
  - 5-dimensional technical bottleneck penetration rules (`机理 / 感知 / 决策 / 安全 / 证据`).
  - Paired Make-vs-Buy (`自研 / 采购 / 拆开`) cost and compensation analysis.
  - Section 9.4 Industry gap reverse-inference from public R&D grants.
- **Heuristic Quality Gate (`check_threads.py`)**: Chapter-level signal density and structural verification script.
- **One-Click DOCX Pipeline (`build_docx.py`)**: Automated Markdown-to-DOCX conversion, 3-level native Word TOC (`TOC \o "1-3"`) injection, CJK path staging, and graceful cross-platform fallback.
